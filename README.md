# Data and code for

**Physically Structured Generalization in Fermionic Neural Quantum States**

This archive contains the processed tables and plotting code used for the four
main figures and four Supplemental Material figures in the accompanying
manuscript. The supported reproduction path starts from the shipped tables; no
training checkpoints or raw wave-function archives are required.

## Quick start

The figure pipeline was tested with Python 3.10.9. From the repository root:

```text
python -m venv .venv
python -m pip install -r requirements.txt
python scripts/reproduce_all.py
```

The last command regenerates the following PDFs under `figures/`:

| Manuscript item | Output |
|---|---|
| Fig. 1 | `figures/fig1_hubbard_generalization.pdf` |
| Fig. 2 | `figures/fig2_structure_mechanism.pdf` |
| Fig. 3 | `figures/fig3_selected_spaces.pdf` |
| Fig. 4 | `figures/fig4_vmc.pdf` |
| Interaction-strength control | `figures/figS_interaction_strength.pdf` |
| Born-sampled-support control | `figures/figS_stochastic_born_support.pdf` |
| H10 truncation control | `figures/figS_h10_truncation_curve.pdf` |
| VMC finite-step common-never control | `figures/figS_band_control.pdf` |

Individual figures can also be regenerated by running their corresponding
`scripts/plot_*.py` file. The complete output-to-input mapping is recorded in
`analysis/generalization_reproducibility_manifest.json`.

## Layout

| Path | Contents |
|---|---|
| `analysis/` | Processed CSV, JSON, and TSV tables consumed by the figure scripts |
| `reference/` | Small reference metadata required by the VMC energy plot |
| `scripts/` | Figure scripts, the all-figure runner, and analysis-provenance helpers |
| `figures/` | Generated output directory; intentionally not versioned |

The pinned dependencies in `requirements.txt` cover the table-to-figure
pipeline. A few provenance helpers document how intermediate tables were
constructed from research runs; they are not invoked by `reproduce_all.py` and
may require the original training code or checkpoints, which are outside this
processed-data archive.
